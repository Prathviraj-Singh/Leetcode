# 02. LCM of Two Numbers

## Problem Statement

Given two positive integers `a` and `b`, find their Least Common Multiple (LCM).

The LCM is the smallest positive integer that is completely divisible by both numbers.

## Examples

**Example 1:**
- Input: `a = 12, b = 18`
- Output: `36`
- Explanation: 36 is the smallest number divisible by both 12 and 18.

**Example 2:**
- Input: `a = 5, b = 10`
- Output: `10`

**Example 3:**
- Input: `a = 7, b = 3`
- Output: `21`

## Constraints

- `1 <= a, b <= 10^9`
